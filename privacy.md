# Privacy Policy

**Home Assistant Personal Link** is a private, single-user application used only by its developer.

## Data accessed
When the owner authorizes the app, it may access Google account data permitted by the scopes the owner approves (for example, calendar or assistant data). This data is used only to run the owner's own Home Assistant automations.

## Storage and sharing
- Data and authorization tokens are stored only on the owner's own self-hosted Home Assistant instance.
- No data is sent to any server operated by the developer.
- No data is sold, shared, or disclosed to third parties.
- No analytics or advertising tools are used.

## Retention and revocation
The owner can revoke the app's access at any time from their Google Account permissions page, and can delete stored tokens by removing the integration from Home Assistant.

## Changes
This policy may be updated; changes will be posted on this page.
