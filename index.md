# Home Assistant Personal Link

Home Assistant Personal Link is a private, single-user smart-home integration. It connects the owner's own self-hosted Home Assistant installation to the owner's own Google account so that Home Assistant can use Google services (for example, calendar or assistant features) on the owner's behalf.

- The app is used only by its developer, on the developer's own devices.
- It is not offered to the public and has no other users.
- It does not collect, sell, or share data with third parties.

Google user data accessed by the app stays inside the owner's own Home Assistant instance.
